# Contributing to StorageKit

Please open a feature request or bug issue first to discuss changes. **Never include local paths, secrets, or deleted-file contents in issues.** Test with disposable fixtures only, never personal files.

Run `./scripts/test.sh` and, on macOS, `./build.sh`. Changes to cleanup validation must include a documented threat model, examples that should be blocked, and smoke tests. Prefer Apple public APIs over private/system manipulation.

The project owner has not selected a license yet. Permission for external redistribution, modification, or reuse is not automatically granted. Select a license before accepting third-party code contributions.
