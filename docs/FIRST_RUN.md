# First launch: Default settings or Customize

StorageKit presents onboarding on first launch. Nothing is deleted during setup.

**Accept Default Settings** finishes immediately with Standard selection mode, no optional review folders, and no Full Disk Access requirement. On a repeat setup this also clears any previously chosen optional review folders, so read the description before using it.

**Customize** opens the folder review step. Desktop, Documents and Downloads each have separate **Choose Folder…** controls. Each invokes the macOS folder picker. A selected path is added only when it exactly matches the proposed folder; cancelling does nothing. **Add Another Folder…** opens the general picker for other directories. All discovered child files are unchecked by default in Storage Cleanup.

Then a separate **Full Disk Access** step explains how to open System Settings. This permission can only be granted by the user, outside StorageKit. It is optional and cannot bypass macOS system-protected paths.

Select **Continue → Finish Setup** to start discovery. Use **Settings → Review Access Setup** to revisit the wizard later. Individual folders can also be added or removed in Settings.
